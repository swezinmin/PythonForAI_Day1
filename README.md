Student Performance Analyzer

Project Description
This project is a Python program that analyzes student performance based on Python scores.

Features
Stores student information using a list of dictionaries.
Validates scores between 0 and 100.
Classifies grades as Excellent, Good, Pass, or Fail.
Calculates the average score.
Finds the highest and lowest scores.
Counts passed and failed students.
Identifies the top student.

How to Run
Install Python.
Open the project folder in VS Code.
Open the terminal.
Run the following command:
python main.py

Technologies Used
Python
Visual Studio Code
